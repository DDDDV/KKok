# 三个资料库的暖红主题与常用功能

2026-09-12：歌曲库、伴奏库、我的演唱统一采用暖朱红、奶油白、暖棕文字和圆角卡片。页面复用应用图标作为品牌插图；资源强调色与 SwiftUI 主题同步，默认唱片封面、演唱舞台和作品回放也改为同一暖色系。

## 布局

- 三页统一为标题、主操作卡片、搜索与筛选、排序、内容列表。
- 可用高度不足 620 pt 时，顶部卡片收紧为横向操作栏；辅助大字号隐藏装饰文案和插图，保留统计与主操作。
- 筛选可横向滚动，列表支持动态字号；无匹配结果时提供清除筛选入口。

## 新增功能（5 项）

1. **收藏歌曲**：歌曲行爱心或更多菜单操作；歌曲库和伴奏库共用收藏状态，均可筛选。收藏写入 `library.json`，旧库没有该字段时视为未收藏。
2. **歌词就绪筛选**：伴奏库仅显示有可用同步歌词的歌曲；没有时间轴的内嵌纯文本不算就绪。
3. **三库排序**：各页可选择最近添加或名称排序，并分别记住设置。伴奏按分离时间排序，作品按录制时间排序。
4. **随机开唱**：从当前搜索与筛选结果中选一首伴奏并进入舞台；空结果和处理期间不可用，进入舞台后由用户开始录音。
5. **作品重命名**：我的演唱 → 更多 → 重命名作品。只原子更新作品清单，保留音频路径、原始录音、歌词与混音设置；空名称及过期版本不能覆盖作品。
